# Sound effects
Selected WAV files from **Helton Yan's Pixel Combat**, supplied by the project owner.
Original filenames are preserved; gameplay mappings live in src/audio/config.js.
Only the seven used clips are included. The supplied directory contained no license
document; this attribution does not assert a license or change the pack's terms.

Each supplied source is a 24-second sequence of six variations. Shipped files
contain only the first variation, converted to mono 44.1 kHz / 16-bit PCM with
5 ms edge fades. Reproduce with scripts/prepare-audio.py and the original pack.
